# The Indian Recipe Book Website

A responsive, aesthetically pleasing website showcasing traditional nutritional recipes from Indian Academic Institutions. This project features a "Classic White and Pale Pink" UI/UX design, focusing on elegance and readability.

## 📖 Project Overview

This website serves as a digital recipe book, allowing users to browse various healthy recipes, view ingredients, methods of preparation, and nutritional information. The content is dynamically loaded using JavaScript, making it easy to add or modify recipes in the future.

### Key Features
* **Elegant UI/UX:** Designed with a soft color palette (Misty Rose, Light Pink, and White) and classic typography (Playfair Display & Lato).
* **Responsive Grid Layout:** Recipe cards adjust beautifully to different screen sizes.
* **Interactive Modals:** Clicking a recipe opens a detailed popup (modal) view without leaving the page.
* **Dynamic Content:** Recipe data is stored in a structured JavaScript array, separating data from the HTML structure.
* **Smooth Navigation:** Sticky navigation bar with smooth scrolling to sections.

## 🛠️ Technologies Used

* **HTML5:** Semantic structure.
* **CSS3:** Custom styling, Flexbox, CSS Grid, and responsive media queries.
* **JavaScript (ES6):** DOM manipulation for rendering recipes and handling modal logic.
* **Google Fonts:** 'Playfair Display' for headings and 'Lato' for body text.
